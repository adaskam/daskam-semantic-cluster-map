# Semantic Cluster Map

"Create a 'Semantic Content Cluster Mind-Mapper' web app for an SEO and content strategy business. The top should have a single input box for a 'Primary Topic' (e.g., Enterprise Cloud Security). When submitted, use an AI backend to generate a visual, interactive node map. The center node is the main topic. Branching off of it should be 4 to 5 secondary content pillars (subtopics). Branching off of those should be specific article/blog title ideas. The UI should be highly visual, clean, and use interactive boxes connected by lines. On the side, include a panel that lists the internal linking strategy and recommended keywords for the active cluster."
